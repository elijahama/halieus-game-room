# Halieus Game Room 3.6.6

Word Game becomes an intentional single-player HGR mode with shared Daily Puzzle competition instead of a one-player multiplayer scoreboard.

- Daily Puzzle uses one deterministic five-letter word for all Halieus players on the same UTC date.
- Practice Puzzle remains single-player and does not affect leaderboard rank or streaks.
- Word Game is server-enforced as a one-seat game; room chat/spectating remains available as optional social chrome.
- The left scoreboard is replaced by Daily Leaderboard / personal-stat presentation with Today, Friends and All Time views.
- Daily ranking is fewest guesses first, then solve time; only the first completed Daily attempt for an account/date counts.
- Personal Word Game stats include daily plays/solves, solve rate, average guesses, fastest solve, current streak and best streak.
- Friends view uses registered Halieus players with whom the account has shared an archived game session.
- The Word Game centre stage, tile grid and input are enlarged on desktop; the social room can be collapsed so the puzzle remains the primary visual focus.
- Existing Wordle feedback rules remain unchanged.
