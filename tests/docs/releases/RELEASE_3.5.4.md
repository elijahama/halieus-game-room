# Halieus Game Room 3.5.4

## UI pass 1 — Game Room showcase

3.5.4 begins the approved UI backlog after the Oracle/HTTPS foundation stabilized.

- Rebuilds the signed-in Home screen around the approved **Immersive Showcase** direction.
- Adds explicit **Create**, **Join with code**, and **Watch a game** actions at the top of the Game Room.
- Promotes a real featured game/current room using only real account, presence, saved-seat, and catalog state.
- Adds compact real status counters for available games, online players, and recoverable rooms.
- Gives Join and Watch distinct intent/copy while preserving one room-code workflow and the same spectator safety model.
- Refines library cards with Available/Beta state and a concrete Create room action.
- Keeps Quick Play, online players, saved rooms, and recent results intact underneath the stronger showcase hierarchy.
- Preserves the website-only Start/Restart/Close workflow; no localhost launcher is restored.

## Scope guard

This pass deliberately does not change game engines, account persistence, Oracle data, room protocols, or game rules. Shared waiting-room standardization and deeper live-game visual polish remain the next UI batches.
