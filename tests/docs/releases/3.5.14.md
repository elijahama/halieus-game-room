# Halieus Game Room 3.5.14

## Corrected deployment blocker

The 3.5.13 source used `gameState.startedAt` in Mega Board live-room summaries even though the authoritative `GameState` field is `gameStartedAt`. Oracle's candidate build therefore failed TypeScript compilation before the release could activate. 3.5.14 corrects the field and restores a passing server build.

## Mega Board trade turn timer

A pending trade remains inside the active player's optional-action window. The server creates one deadline for that window and does not replace an expired deadline with a fresh 2:30 period. Repeated trade/state broadcasts reuse the same scheduler. When the deadline expires, any unresolved trade is cancelled and the turn advances.

The client also keeps the last authoritative deadline for the current turn while the outgoing trade UI is open so transient state updates cannot visually bounce the timer back to 2:30.
