HALIEUS GAME ROOM 3.5.2

- Local start/restart/stop controls live under dev-tools\Local Development.

IMPORTANT
Extract this as a fresh replacement project folder rather than merging it over an older folder, otherwise obsolete Restart/Close files from the previous layout can remain behind.

Keep your Oracle private SSH key outside shareable project ZIPs, preferably under %USERPROFILE%\.ssh\.

HTTPS
