# Beta Tester Guide

## What to test

Please play naturally first. When something feels wrong, record the exact action immediately before it happened.

Useful test areas include:

- desktop and tablet layout
- light and dark mode readability
- physical dice / Speed Die animation
- token movement
- buying and rent
- auctions
- Bus Tickets
- Jail
- Chance and Community Chest
- building and mortgages
- trading
- debt and bankruptcy
- AI and Human Autopilot
- refresh / rejoin
- host ending the room

## Reporting an issue

Open **Menu → Send feedback** and choose the closest category. Include what you expected, what actually happened and whether the issue happened every time.

For a blocking bug, also capture a screenshot and the host terminal output if possible.
