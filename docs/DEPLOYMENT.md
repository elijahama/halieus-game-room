# Halieus Production Deployment — 3.5.27+

## Normal owner commands

### Start
`Start Halieus Game Room.cmd` opens the existing live website only.

### Restart
`Restart Halieus Game Room.cmd` closes/reopens the dedicated Halieus website window and adds a cache-busting URL. It does not publish code.

### Update
`Update Halieus Website.cmd` is the explicit application deployment command. It discovers the existing Oracle SSH credential locally, packages this exact release, uploads it, builds a candidate on Oracle, activates it, and verifies the exact release.

## Deployment helper ownership and sync

The version-controlled Oracle deployment authority lives under `tests/dev-tools/Oracle Quick Deploy/`. In particular, `deploy-from-windows.ps1` and `quick-install.sh` are tracked there so release checks and CI can parse and audit the same deployment logic used by the owner-PC workflow.

The owner-PC working mirror at `dev-tools/Oracle Quick Deploy/` is intentionally ignored/private. STEP 9 of `Update HGR GitHub.cmd` refreshes `deploy-from-windows.ps1` and `quick-install.sh` from the tracked canonical copies immediately before website deployment. The local mirror is therefore not a second source of truth and should not be hand-edited as the durable fix location.

Private `update-website.ps1`, SSH keys and production credentials remain local and must never be committed. If the private owner wrapper is absent, the updater can fall back to the refreshed Oracle deployment helper using the machine's existing SSH authentication.

A final `throw` in `deploy-from-windows.ps1` reports a non-zero remote installer result; it is not by itself the root cause. Diagnose the Oracle installer output immediately above it first. For example, an npm security-gate failure is fixed in dependencies and the lockfile, not by weakening the wrapper or suppressing the error.

## Exact-release verification

A release contains `RELEASE.json`, generated by:

```powershell
node scripts/release-integrity.mjs --write
node scripts/release-integrity.mjs --verify
```

The manifest includes a SHA-256 release fingerprint. The same fingerprint is compiled into the server. After deployment, Oracle local `/health` must return both the expected `version` and `releaseFingerprint`.

The public `https://halieus.remotewire.net/health` request is useful diagnostics, but Oracle-local exact verification is the deployment authority. This avoids a Windows TLS/proxy/DNS problem falsely reporting a successful application update as failed.

## Security gate

The release CI and Oracle quick installer both enforce `npm audit --audit-level=high`. A high or critical npm advisory is therefore a deployment blocker by design, and a non-zero remote installer exit can surface at the Windows deploy wrapper as an Oracle installation failure.

Do not disable, bypass, or lower this gate to get a release out. Patch or override the affected dependency, refresh `package-lock.json`, verify a clean `npm ci` and a passing high/critical audit, then run the normal regression/CI path before attempting the Oracle deployment again.

## Routine Update deliberately does not

- run `apt`, `apt-get`, `dnf`, or package-manager provisioning;
- install/configure nginx;
- run Certbot;
- create the service account or production environment file;
- configure swap;
- replace `/var/lib/halieus-game-room`.

If those prerequisites are missing, Update stops and tells the owner to use the separate provisioning/recovery operation.

## One-time provisioning

The canonical provisioning script is tracked at `tests/dev-tools/Oracle Quick Deploy/provision-oracle.sh`. It is intentionally separate from the routine updater and is for first-time/recovery server preparation, not every release.

## Rollback safety

The Oracle installer builds outside `/opt/halieus-game-room`. The existing application stays available until the candidate is built. After activation, failure to match the exact version/fingerprint restores the previous application directory automatically.

Persistent production data remain under:

`/var/lib/halieus-game-room`
