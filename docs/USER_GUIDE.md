# Player Guide

## Joining a game

Players can join from the main page with a room code or from a direct invite URL in the form `/join/ROOMCODE`.

A waiting room supports up to eight active players. The host starts the match when at least two players are present.

## Your turn

The action panel changes with the server-controlled turn phase. Depending on the situation it can show:

- Roll Dice
- Use Bus Ticket
- Buy / Pass to Auction
- Jail choices
- Speed Die choices
- Card continuation
- Debt-resolution actions
- Optional building, mortgage, trade and end-turn actions

When Human Autopilot is enabled, manual turn controls are locked until control is taken back.

## Cash privacy

Your own cash is visible to you. During active play, opponents' cash is shown as private. Opponent ownership, development, mortgage and public card/ticket counts remain inspectable from the Table tab. Spectators are read-only and can see exact cash for every seat.

## Rejoining

Refreshing the same browser should recover the seat automatically. A different browser or device requires the room code, player name and recovery key. Treat the recovery key like a private seat credential.

## Leaving

A non-host can leave and forfeit. The host can end the room for everyone. Closing or refreshing the browser does not immediately count as a deliberate quit because the host has a reconnection grace period.
